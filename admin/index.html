Sign in to edit the website

Changes you publish here are saved to the website's GitHub repository and go live on the site in about a minute.

First time? Create an access key on GitHub:

  1. Open GitHub → New fine-grained token (sign in as the repo owner).
  2. Token name: Younus admin. Expiration: choose how long it should work (e.g. 1 year).
  3. Repository access: Only select repositories → .
  4. Permissions → Repository permissions → Contents: Read and write.
  5. Click Generate token, copy it and paste it below.

Keep this key private — anyone with it can change the website. Only sign in on your own devices.
