# Younus Foodstuff Trading LLC — website

Live at **https://younus.ae** (GitHub Pages, deployed from `main`).

## Editing products and shop settings

Open **https://younus.ae/admin/** and sign in with a GitHub fine-grained access key
(Repository access: this repo only · Permissions → Contents: Read and write).

From there you can add, edit, hide, reorder and delete products (English and Arabic),
upload product photos, manage categories, and change the WhatsApp number and delivery fees.
Click **Publish changes** — the site updates in about a minute.

## Files

- `index.html` — the website (English / Arabic)
- `data.json` — products, categories and shop settings (written by the admin panel)
- `images/` — product photos uploaded from the admin panel
- `admin/index.html` — the admin panel
